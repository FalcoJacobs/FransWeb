Er zijn 3 verschillende soorten werkwoorden:

  1. Werkwoorden op -ER (bijv: Parler, Aimer, Donner, ...
  2. Werkwoorden op -IR (bevat 3 types:
    1. Type finir (bijv: Finir, Choisir, Grandir, ...
    2. Type Dormir (bijv: Dormir, Mentir, Partir, ...
    3. Type Ouvrir (bijv: Ouvrir, Offrir, Souffrir
  3. Werkwoorden op -RE (bijv: Rendre, Vendre, Descendre, ...

1. Werkwoorden op -ER

Formule: Stam + uitgangen
Stam: Infinitief - ER

voorbeelden:

Spellings uitzonderingen voor werkwoorden op -ER

  • Voor -ons:
    • c --> ç (commencer)
    • g --> ge (manger)
  • Voor een doffe e:
    • Y --> i (nettoyer)
    • e --> è (acheter)
    • é --> è (céder)
    • l --> ll (appeler)
    • t --> tt (jeter)
